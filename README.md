## GitHub Pages

上传本目录内容到独立仓库后，在Settings → Pages中选Deploy from a branch，分支main，目录/(root)。页面地址由GitHub返回，通常为https://账号.github.io/仓库名/。

.nojekyll保持静态资源原样发布。所有素材均为相对路径，支持仓库子路径；无本机路径依赖。

截图与演示中的商标和界面属于各自权利人，页面用于竞品体验研究，不代表品牌官方观点。
